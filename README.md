# 图床上传工具

一个简单易用的Chrome浏览器扩展，用于快速上传图片到111666图床并获取图片链接。

## 功能特点

- 支持图片拖拽上传
- 支持图片粘贴上传
- 支持快捷键调用悬浮窗（默认为Ctrl+Shift+U）
- 返回多种格式的图片链接（Markdown、HTML和URL）
- 简洁美观的用户界面

## 安装方法

### 开发模式安装

1. 打开Chrome浏览器，在地址栏输入 `chrome://extensions/`
2. 开启右上角的「开发者模式」
3. 点击左上角的「加载已解压的扩展程序」
4. 选择本项目文件夹

## 使用方法

### 上传图片

#### 通过弹出窗口

1. 点击Chrome工具栏中的扩展图标
2. 将图片拖拽到上传区域，或点击「选择图片」按钮
3. 也可以复制图片后，在弹出窗口中粘贴（Ctrl+V）
4. 上传成功后，可以复制不同格式的图片链接

## API说明

本扩展使用111666图床API，详细API说明请参考 `API/111666图床API文档.txt`

## 注意事项

- Auth-Token仅作为删除图片的凭据，请妥善保管
- 上传的图片将保存在111666图床服务器上
- 如需删除已上传的图片，请使用API中的删除接口
